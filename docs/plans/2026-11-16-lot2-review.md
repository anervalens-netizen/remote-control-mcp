This is the development agent's disposition of the initial candidate `162ab38caae91f63efd9eb4560817d4f0163091c` against base `c736962dcb047330cc7eb11ceb59e1b3cfce5169`. It is source engineering evidence, not owner risk acceptance or deployment approval.

The revised candidate still requires its combined gate, both exact-head reviews, version-bound public disposition and grouped review closure before normal integration.

| DSH item | Development disposition | Change, evidence and remaining scope |
|---|---|---|
| 1. Routine signal shutdown | Fixed | Agent SIGTERM/SIGINT call `app.close()`. Real child-agent tests cover clean markers, claim release, new boot UUIDs and failed-bind cleanup. Clean restart intervals remain explicit observation gaps. |
| 2. Diagnostic receipt authenticity | Dismissed as an added trust guarantee; contract clarified | Receipt matching correlates a dispatch inside the configured endpoint/shared-bearer boundary. It is not a signed endpoint attestation or a durable execution/effect receipt. `attributionScope` and the contract now say so explicitly. A MAC based on a bearer disclosed to a substituted endpoint would not establish independent endpoint authenticity. |
| 3. Agent failure hides controller evidence | Fixed | `usage_report` retains controller observations and returns `agent: null` with fixed unsupported/timeout/error categories. SDK fixtures cover missing routes, transport/HTTP failures, incomplete contracts and deadlines. Healthy reads still use one dispatch. |
| 4. Complete public same-window workflow | Deferred; scope/status corrected | The bounded reconciliation primitive exists, but the public tool returns separate snapshots. OBS-04 is active. Reopen through OBS-04/HIS-02 to deliver bounded collection of an explicit, complete window and operator reconciliation. Private runtime qualification does not close this public workflow requirement. |
| 5. Query-bearing route categories | Fixed | Classification uses pathname only. Known metrics/health routes retain their fixed categories; query and fragment values never become dimensions. Four regressions reproduce the old categories. |
| 6. Unbounded or duplicate capability selection | Fixed with scope clarified | Selection is limited to 64 entries before probes, including implicit inventory, and canonical aliases are deduplicated. The catalog/result identify a per-endpoint timeout. A shared cross-caller quota was not promised and is not implemented. |
| 7. Counter and history lifetimes | Fixed | `counterScope`, `history.scope` and `coverage.persistenceScope` distinguish process counters from retained UTC daily aggregates. Process restart does not imply restoration of prior process totals. |
| 8. Concurrent aggregate writers | Fixed for exclusion and visible failure; crash limitation retained | An exclusive held writer claim and identity check prevent concurrent publication. Cross-process tests cover collisions, abrupt owner death, preserved aggregate bytes and refusal to remove another claim. Missing ownership reports `state_writer_lost`, unavailable persistence and required repair. Orphaned claims need inspection; no automatic takeover is claimed. |
| 9. Probe deadline counted as cancellation | Fixed | The first combined abort reason separates `TimeoutError` from caller abort. Real stalled HTTP tests assert timeout-only and cancellation-only counters. The underlying mapping predated the new counters. |
| 10. Truncated response counted as malformed JSON | Fixed | Complete invalid JSON remains a protocol error; a broken response-body transport is a network error. Real HTTP fixtures distinguish them. The earlier mapping predated this observation feature. |
| 11. Single-read cancellation | Fixed | The SDK cancellation signal reaches both the capability check and file read. Cancelling the first phase prevents dispatch of the second. |
| 12. Raw-body completion and abandonment | Fixed | Stopping after all declared bytes counts as completion; stopping early remains cancellation. A deadline also cancels an uniterated response body and finishes the dispatch once. |
| 13. Real HTTP lifecycle coverage | Fixed in tests | Actual `createMcpHttpServer` tests exercise complete response and aborted request with single completion; the existing real SSE case covers premature close after status 200. |
| 14. Normal abort appears duplicated | Fixed | HTTP lifecycle signals are coalesced before the observer's finish operation. An actual abort produces one disconnected completion without incrementing duplicate completions. |
| 15. Reusing a process instance UUID | Dismissed for the production contract | Production creates a fresh runtime UUID per boot, verified by real restart tests. The constructor now states this precondition. Restoring only the last persisted sequence would not prevent reuse of an unflushed tail and would misrepresent a durable allocator. |
| 16. Shared-bearer access to correlation metadata | Dismissed as an added isolation guarantee; boundary clarified | Detailed samples use the existing credential-holder diagnostics boundary. UUID labels are not credentials or authenticated human identities; per-caller isolation is not promised. Samples exclude lease tokens, command bodies and raw results. |
